# 初一黑客松网站 Implementation Plan

**Goal:** 复用 GOTC 现有官网、Python 评分服务和实时看板，交付初一活动的独立官网与两阶段评审平台。

**Architecture:** 保留零构建 HTML/CSS/JS 前端、Python 标准库与 SQLite 后端。独立 /chuyi URL、端口、数据库、cookie 与 systemd 服务；原 GOTC 源码与运行数据不变。

**Tech Stack:** HTML、CSS、原生 JavaScript、Python 3.11+、SQLite、Nginx。

1. 核实《GOTC黑客松官网》与初一主视觉、执行方案、奖项聊天，沿用原版排版与资产，替换活动内容。
2. 后端分离 roadshow/final 评委与评分；支持6/8名晋级、边界同分人工确认、冻结名单、四奖项评分与确认，隐藏成绩时不泄漏排名。
3. 前端保留原工作台布局，新增独立路演/决赛入口、两类看板、后台阶段控制与晋级/奖项确认。
4. 复用独立服务部署脚本，适配 /opt/chuyi-hackathon、5275、/chuyi；先核实不冲突，保留回滚与既有服务健康检查。
5. 用隔离临时数据库验证权限、阶段隔离、并列晋级、决赛与发布；验证前端导航、移动版和完整一次评分流程。
6. 发布独立云服务，核实公网资源与接口；输出管理员私有访问文件、操作说明和不含数据/密钥的源代码包。

已从初一学生手册、四奖证书聊天和用户最新执行方案截图核实活动文案、四赛道、四奖及建议赛程。路演晋级默认6名并提供8名开关；评分权重沿用GOTC，公开标注为平台配置以免混作已定规程。
