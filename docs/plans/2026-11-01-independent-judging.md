# 独立评审与定时开放

现场需求：路演评委输入统一邀请码后直接评分，不再手动选择身份；2026年11月1日北京时间13:00自动开放路演。决赛独立显示全部23队，点击队伍标签填写四项25分，不等待路演名单或开关。

## 实现选择

路演使用浏览器持久随机标识绑定独立评委账号。所有浏览器共用一个账号会互相覆盖评分；每次登录创建账号则会重复计票，因此同一浏览器必须稳定复用身份。邀请码仍由服务器校验，设备标识本身不是通行凭证。

路演定时开放由后端持久设置驱动，到点第一次请求原子触发，浏览器不决定是否开放。开放后人工关闭不被定时逻辑再次覆盖；服务重启也保留计划和完成状态。

决赛默认独立模式，所有队伍可供选择，两轮可以分别开放。路演排名和前6/8名名单作为现场参考，不限制决赛评分入口。决赛实际参与队伍按至少一份正式评分确定；未评分队伍不阻止颁奖，已参与队伍须全部收齐6份并关闭决赛后才能确认奖项。

现有单实例SQLite事务和HTTP接口继续使用。成绩请求间隔改为1秒，提交立即落库；保留超时、断线恢复和编辑保护。暂不引入长连接或额外服务，避免现场部署复杂度。

## 验证重点

- 路演无需身份选择，独立浏览器分数隔离，同浏览器重登不新增身份。
- 13:00前拒绝评分、到点自动开放、之后人工关闭、重启恢复及并发请求。
- 决赛不依赖路演名单/阶段/公开状态；全部队伍标签可选择。
- 只评部分队伍也能在收齐6份后确认专项奖与MVP。
- 23队大屏分页、1秒轮询不重叠、输入及慢请求保护。
